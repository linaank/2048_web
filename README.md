## О работе

Игра 2048 в стиле «Губки Боба» на HTML, CSS и JavaScript. Классический функционал игры: сдвигать плитки и объединять одинаковые, набирать очки.

## Возможности

- игровое поле 4×4 с анимацией появления, движения и объединения плиток;
- подсчёт текущего счёта и рекорда;
- отмена последнего хода (недоступна после окончания игры);
- кнопка «Заново»;
- экран окончания игры с сохранением результата по имени;
- таблица лидеров с 10 лучшими результатами;
- сохранение игры, рекорда и таблицы лидеров в `localStorage`;
- адаптивная вёрстка для компьютеров и телефонов.

## Управление

| Устройство | Как играть |
|---|---|
| Компьютер | стрелки на клавиатуре; `Esc` закрывает таблицу лидеров |
| Телефон | свайпы по полю или кнопки со стрелками |
